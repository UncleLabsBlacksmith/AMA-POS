# 🏪 ระบบ POS ร้านชำอาม่า

ระบบขายหน้าร้านด้วย **Django + Tailwind CSS v4** ออกแบบมาเพื่อ **ผู้สูงอายุใช้งานเองได้** โดยเฉพาะ

---

## เปิดใช้งาน

```bash
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_shop          # ใส่สินค้าตัวอย่าง 28 รายการ (ทำครั้งเดียว)
python manage.py runserver 8010
```

เปิดเบราว์เซอร์ไปที่ <http://localhost:8010>

> ไฟล์ `static/store/tailwind.css` ที่ build แล้วถูกเก็บไว้ในโปรเจกต์ด้วย
> **ถ้าแค่จะเปิดร้านขายของ ไม่ต้องติดตั้ง Node** — ใช้ได้เลยแบบออฟไลน์

สร้างบัญชีผู้ดูแล (สำหรับหน้า `/admin/` — ไม่จำเป็นต้องใช้ในการขายประจำวัน):

```bash
python manage.py createsuperuser
```

## แก้หน้าตา (Tailwind)

ต้องมี Node เฉพาะตอนจะแก้ดีไซน์เท่านั้น

```bash
npm install          # ครั้งแรกครั้งเดียว
npm run watch        # แก้ไฟล์แล้ว build ใหม่ให้อัตโนมัติ ระหว่างพัฒนา
npm run build        # build ครั้งเดียวแบบ minify ก่อนเอาไปใช้จริง
```

| ไฟล์ | คืออะไร |
|---|---|
| `static/store/tailwind.input.css` | **ไฟล์ที่ใช้แก้** — สีของร้าน ฟอนต์ และคลาสที่ใช้ซ้ำ (`.btn` `.tile` `.fld` ฯลฯ) |
| `static/store/tailwind.css` | ไฟล์ผลลัพธ์ที่ build แล้ว (~25 KB) **อย่าแก้ตรงนี้ จะถูกทับ** |

เปลี่ยนสีทั้งร้านได้ที่บล็อก `@theme` ในไฟล์ input เช่น `--color-paper` คือสีพื้นหลัง

**สำคัญ:** ถ้าเพิ่มคลาส Tailwind ใหม่ในเทมเพลตหรือใน `pos.js` ต้อง `npm run build` ใหม่
เพราะ Tailwind จะใส่มาเฉพาะคลาสที่หาเจอในไฟล์เหล่านั้น (ดูรายการที่สแกนได้จาก `@source` ในไฟล์ input)

## ออกแบบมาให้คนอายุ 80 ใช้ได้อย่างไร

| ปัญหาของผู้สูงอายุ | สิ่งที่ทำในระบบนี้ |
|---|---|
| สายตาไม่ดี | ปุ่ม 🔍 ขยาย **ทั้งหน้า** ได้ 4 ระดับ (21→30px) ปุ่มและระยะห่างโตตามตัวหนังสือด้วย เพราะ Tailwind วัดทุกอย่างเป็น `rem` — ระบบจำขนาดที่เลือกไว้ให้ |
| อ่านตัวเลขเล็กไม่ออก | ยอดรวมและ **เงินทอน** แสดงตัวใหญ่มาก สีเขียว/แดงตัดกันชัด |
| อ่านหนังสือไม่ถนัด | ทุกสินค้ามี **อิโมจิ/รูปใหญ่** และระบบ **พูดภาษาไทย** บอกชื่อของ ราคา และเงินทอน |
| มือสั่น กดพลาด | ปุ่มสูงอย่างน้อย 4.75rem (~100px ที่ขนาดเริ่มต้น) ปุ่มเก็บเงินสูงกว่านั้นอีก เว้นระยะห่างชัดเจน |
| คิดเลขในใจไม่ทัน | ไม่ต้องพิมพ์เลข — กดปุ่มใบละ 20/50/100/500/1000 ตามที่ลูกค้ายื่นมา ระบบทอนให้เอง |
| จำเมนูซ้อนไม่ได้ | ไม่มีเมนูซ่อน ทุกอย่างอยู่บนแถบเดียวตลอดเวลา |
| กลัวกดผิดแล้วแก้ไม่ได้ | ลบทีละชิ้นได้ ยกเลิกทั้งบิลได้ และบิลที่เก็บเงินไปแล้วก็ยกเลิกย้อนหลังได้ (ของกลับเข้าสต๊อกเอง) |
| ไม่อยากล็อกอินทุกครั้ง | หน้าขายเปิดใช้ได้ทันที ไม่ต้องใส่รหัส |

## ฟีเจอร์ร้านชำไทยโดยเฉพาะ

- **ซื้อเชื่อ / ลงบัญชี** — ลูกค้าประจำเอาของไปก่อน จดชื่อไว้ ระบบรวมยอดค้างให้อัตโนมัติ และตัดยอดเมื่อมาจ่าย
- **รับโอน / สแกนจ่าย** — แยกยอดจากเงินสด เวลาสรุปตอนเย็นไม่งง
- **บาร์โค้ด** — ถ้ามีเครื่องสแกน ยิงลงช่องค้นหาได้เลย ระบบเพิ่มของให้ทันที (ไม่มีเครื่องก็กดรูปเอาได้ปกติ)
- **สต๊อก + เตือนของใกล้หมด** — เห็นได้ในหน้ายอดวันนี้ ว่าต้องสั่งอะไรเพิ่ม
- **ใบเสร็จพิมพ์ได้** — จัดหน้ามาให้เหมาะกับกระดาษสลิป

## ก่อนเอาไปใช้จริง

ตอนนี้ตั้งค่าไว้สำหรับใช้ในบ้าน/ในร้าน (เครื่องเดียว หรือแลนวงเดียวกัน) ถ้าจะเปิดออกอินเทอร์เน็ต ต้อง:

1. `DEBUG = False` และตั้ง `ALLOWED_HOSTS` เป็นโดเมนจริง (ตอนนี้เป็น `['*']`)
   — อย่าลืม `npm run build` และ `python manage.py collectstatic`
2. เปลี่ยน `SECRET_KEY` เป็นค่าใหม่ที่เก็บเป็นความลับ
3. ใส่ระบบล็อกอินให้หน้าขาย (ตอนนี้ตั้งใจให้เปิดได้เลยเพื่อความสะดวกของอาม่า)
4. เสิร์ฟไฟล์ static/media ด้วยเว็บเซิร์ฟเวอร์จริง และสำรองไฟล์ `db.sqlite3` สม่ำเสมอ
